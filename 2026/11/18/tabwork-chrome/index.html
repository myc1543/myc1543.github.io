用 Tabwork 整理 Chrome 标签页：下次排查，从同一个文件夹开始

发表于 2026-11-18 分类于 实用工具 本文字数： 1.8k 阅读时长 ≈ 2 分钟
用一个订单排查的例子，介绍 Tabwork 如何归组、保存和按任务恢复网页，附 Chrome 扩展安装包及可复制的 Agent 安装提示词。

排查一笔订单时，接口文档、监控面板和具体请求的日志往往同时开着。查完以后，关掉日志很容易，关掉监控页却会犹豫一下：下次还得从哪里把它找回来？

我做了一个 Chrome 扩展 Tabwork。它在浏览器侧栏里给每项任务留一个文件夹。常用入口可以存进去，这一轮排查临时打开的页面也可以放在旁边。两种页面关掉以后，有各自的去处。

用一个文件夹走完一次排查

  1. 打开 Tabwork 侧栏，点右上角「⋯ → 新建文件夹」，取名「订单排查」。
  2. 点「＋ 添加链接」，把接口文档和监控面板存进这个文件夹。网页已经开着时，也可以在工作台里右键点它，选「保存为链接」。
  3. 把本次请求的日志页归入同一任务。侧栏里展开「订单排查」就能一起看到它们。点击已经打开的条目会切回原标签，尤其适合监控页开在另一个窗口的时候。

什么时候该点「保存为链接」？ 问自己一句：下次换一笔订单，我还会打开这个地址吗？如果是监控首页，值得保存；如果是带着这次请求参数的详情页，临时归组就够了。

我做的操作 下次还能找到什么
关闭已经保存为链接的监控页 文件夹里保留入口，点击即可重开
单独关闭临时归组的日志页 这条临时记录随标签移除，文件夹和常用入口仍在
正常退出 Chrome，日志页当时仍在组内 下次启动时，可以预览待恢复的网页，决定是否继续这项任务

第二天，只打开今天要做的事

昨天可能同时开着「订单排查」和「技术调研」，今天只想接着查订单。Tabwork 1.4.0 的启动询问可以按文件夹选范围。展开清单看看标题，再点「打开」。Chrome 已经恢复的相同网址会跳过，选「暂不打开」也会保留清单。这里恢复的是网址，表单草稿和页面滚动位置取决于网页和浏览器。

Chrome 自带的标签组已经可以保存和重开一组网页。Tabwork 适合另一种更细的习惯：同一项工作反复做，常用入口固定，每次的临时页面却不同。 下次点开「订单排查」，监控和文档还在那里，上一次已经查完并关掉的日志也干干净净。Chrome 标签组说明

安装，也可以交给 Agent

下载 Tabwork 1.4.0 安装包。这个包只包含扩展运行文件，适用于桌面 Chrome 116 及以上版本，无需安装 Node.js。解压到一个长期保留的位置，进入 chrome://extensions/，开启「开发者模式」，点「加载已解压的扩展程序」，选择直接包含 manifest.json 的 extension 文件夹。安装完成后，点击扩展图标即可打开工作台。

如果你的 Agent 能操作本机文件和浏览器，可以直接复制下面这段：

Tabwork 用 tabs 和 tabGroups 读取标签标题、网址并管理分组，用 sidePanel 展示工作台，用 storage 在本机保存文件夹和链接。启用系统重复提醒时会用到 notifications。安装清单没有申请网站访问权限，也没有注入网页脚本。第一次试用，只需建一个文件夹、存一个常用网址，再关掉那个标签：侧栏里留下的入口，就是你下一次开始工作的地方。
