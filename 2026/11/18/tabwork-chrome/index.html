用 Tabwork 整理 Chrome 标签页：把同一件事的网页放在一起

发表于 2026-11-18 分类于 实用工具 本文字数： 1.9k 阅读时长 ≈ 2 分钟
用旅行规划、在线学习和购物比价举例，了解怎样保存常用链接、收起临时标签，下次只打开需要的网页。附安装包和可复制的 Agent 安装提示词。

为了安排一个周末，我可能在 Chrome 里打开十来个网页：一张步行路线图、几家民宿、博物馆的预约入口，还有临时搜来的天气预报。晚上合上电脑时，最想留到明天的是那张花了半小时才找到的路线图。可要是把所有网页都留着，明天又得猜，哪一家民宿是我已经看过、决定放弃的？

Tabwork 是我做的一个 Chrome 标签页扩展。它让你在侧栏里给一件事建一个文件夹：想留到以后再看的网址可以保存为链接，还在挑、还在读的页面可以临时放在旁边。

第一次用，建一个「周末出游」文件夹

  1. 点 Tabwork 图标打开侧栏，选「⋯ → 新建文件夹」，输入「周末出游」。
  2. 点「＋ 添加链接」，把步行路线和博物馆预约入口存进去，起两个一眼认得出的名字。如果网页已经在工作台里，右键点它也可以选「保存为链接」。
  3. 把正在比较的民宿页面临时归入这个文件夹。看中一家就保存链接，排除一家就关掉标签。想看路线时，点侧栏里的「步行路线」。它要是已经开在另一个窗口，Tabwork 会直接带你过去。

关掉网页以后，还能找回来吗？ 这取决于你之前怎样放置它。

你做的操作 下次打开工作台
把路线图保存为链接，然后关闭标签 文件夹里仍有「步行路线」，点一下就能重开
把民宿页面临时归组，看完后单独关闭标签 这条临时记录随标签移除，其他候选仍在
民宿还没挑完，保留组内标签并正常退出 Chrome 下次启动时，可以预览待恢复清单，再决定打开哪些任务的页面

明天只想接着学摄影

同一套用法也适合日常学习和购物。学摄影时，把课程目录保存为链接，当天读的几篇构图教程临时归组；挑耳机时，把入围的两个型号存下来，查完一篇评测就关掉。文件夹的名字由你定，一件事做完也可以换下一件。

有多个文件夹待恢复时，Tabwork 1.4.0 会在 Chrome 启动时让你选范围。今天打算学摄影，就选「学摄影」；等到周末要出门，再选「周末出游」。点开清单能先看标题和数量，确认后只打开所选范围里尚未打开的网址。「暂不打开」也会保留清单。重新打开的是网页地址，表单草稿和滚动位置取决于网页及浏览器。

如果平时只想把一组网页一起关掉、一起打开，Chrome 自带的标签组也支持保存和重开。我用 Tabwork 的理由是，每次展开同一个文件夹，都能在常用入口旁边看到眼下还没处理完的页面。Chrome 标签组说明

安装，也可以交给 Agent

下载 Tabwork 1.4.0 安装包。这个包只包含扩展运行文件，适用于桌面 Chrome 116 及以上版本，无需安装 Node.js。解压到一个长期保留的位置，进入 chrome://extensions/，开启「开发者模式」，点「加载已解压的扩展程序」，选择直接包含 manifest.json 的 extension 文件夹。安装完成后，点击扩展图标即可打开工作台。

Tabwork 用 tabs 和 tabGroups 读取标签标题、网址并管理分组，用 sidePanel 展示工作台，用 storage 在本机保存文件夹和链接。启用系统重复提醒时会用到 notifications。安装清单没有申请网站访问权限，也没有注入网页脚本。第一次试用，只需建一个文件夹、存一个常用网址，再关掉那个标签：侧栏里留下的入口，就是你下一次开始工作的地方。
